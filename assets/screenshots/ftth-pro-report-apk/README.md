# Katalog Screenshot — FTTH-Pro Report (Android APK)

Folder ini berisi tangkapan layar resmi aplikasi Android **FTTH-Pro Report v1.0.0** yang dikembangkan oleh **Syaiful Wachid** (Senior Project Designer Fiberhome Indonesia).

Aplikasi ini digunakan oleh tim teknis lapangan, SPV vendor, dan subcon untuk manajemen cluster, inspeksi harian, monitoring progres instalasi tiang & kabel, serta pembuatan Daily Report otomatis.
