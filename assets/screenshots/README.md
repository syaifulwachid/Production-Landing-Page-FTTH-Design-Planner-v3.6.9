# Panduan Menaruh & Menyiapkan Screenshot Produk

Folder ini adalah tempat penyimpanan resmi seluruh tangkapan layar (*screenshot*), rekaman demo visual, dan aset grafis antarmuka untuk masing-masing produk software Anda.

Agen AI dan tim marketing akan menggunakan gambar-gambar di dalam folder ini sebagai bahan pembuatan **Banner Promo, Carousel LinkedIn, Thumbnail YouTube, dan Mockup Presentasi**.

---

## 1. Struktur Folder Screenshot

Letakkan file screenshot Anda (format `.png` atau `.jpg` beresolusi tinggi/tidak blur) ke dalam masing-masing sub-folder berikut:

```text
assets/screenshots/
├─ ftth-design-planner/      <- Screenshot FTTH Design Planner v.3.6.9
├─ kmz-to-hpdb-converter/    <- Screenshot KMZ To HPDB & BOQ Converter v3.2
├─ radial-menu/              <- Screenshot RadialMenu Setup v1.34.0
├─ tssr-geo-tag/             <- Screenshot TSSR Geo TAG Capture v3.0
└─ ftth-pro-report-apk/      <- Screenshot FTTH-Pro Report (Android APK)
```

## 3. Tips Pengambilan Screenshot Terbaik
1. **Gunakan Mode Fullscreen / Resolusi Tinggi**: Minimal 1920x1080 (FHD) agar detail teks menu dan garis kabel terlihat tajam.
2. **Hindari Informasi Sensitif**: Jika menggunakan file proyek asli klien, pastikan nama klien rahasia atau data sensitif disamarkan/diganti nama demo (*dummy project*).
3. **Background AutoCAD Gelap (Dark Mode)**: Warna garis kabel (Cyan, Orange, Magenta, Green) akan sangat kontras dan terlihat profesional di atas background gelap.
