## 🎯 Detail Fungsi Tiap Kartu (Card), Tombol, & Kontrol Form

### 1. Radial Overlay UI (`01_Radial_Overlay_UI`)
* **Pusat Kontrol Cepat (Center Hub):**
  - Tombol pensil ✏️ di tengah bertindak sebagai pemicu mode edit.
  - Klik kanan pada pusat lingkaran memunculkan daftar switcher profil menu tanpa membuka window pengaturan.
  - Tombol navigasi ➕, ➖, ✥, dan ⚙️ tersusun simetris di sekeliling lingkaran pusat pada mode edit.
* **Cincin Konsentris Luar (Concentric Rings):**
  - Membuka submenu bertingkat dengan distribusi sudut adaptif (*Smart Angle Calculation*) sehingga submenu hanya mengembang ke arah luar segmen induk tanpa menghalangi pandangan ke area layar lainnya.
* **Toolbar Bawah Melayang:**
  - Terdiri dari 5 kartu aksi instan (*Submenu, Paste Teks, Makro, Web, Buka App*). Pengguna dapat menarik tombol aksi ini langsung ke segmen menu, atau menyeret file / folder apa pun langsung dari Windows Explorer.

---

### 2. Form Settings - Tab General (`02_Settings_General`)
* **Open Hotkey Card:** Merekam kombinasi keyboard global melalui Windows API `RegisterHotKey` (misal: `Shift + Alt + R`).
* **Quickmode Card (Toggle):** Saat aktif, menu radial langsung menjalankan perintah pada segmen yang disorot begitu hotkey dilepas, memotong waktu klik mouse.
* **Directional Hover Card (Toggle):** Menggunakan algoritma vektor arah mouse (*Angular Bisector Calculation*) untuk menyorot menu secara instan tanpa perlu mouse menyentuh lingkaran.
* **Pass-Through Click Card (Toggle):** Memanfaatkan fitur Win32 `WS_EX_TRANSPARENT` pada area kosong di luar lingkaran menu agar klik mouse dapat menembus ke jendela aplikasi di baliknya.
* **Tampilkan di Tengah Layar Card (Toggle):** Menempatkan menu tepat di pusat monitor tempat kursor berada (sangat optimal untuk setup multi-monitor).
* **Launch at Startup Card (Toggle):** Mengatur registri `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` agar aplikasi langsung aktif saat Windows booting.
* **Pro License & QRIS Card:**
  - Barcode QRIS statis untuk aktivasi lisensi seumur hidup (Rp 50.000).
  - Tampilan Hardware ID (HWID) unik perangkat dengan tombol copy 1-klik.
  - Tombol permintaan aktivasi otomatis dan input kunci lisensi offline (SHA-256 Signature).
* **Data Management Card:** Tombol akses folder konfigurasi JSON, penampil log real-time, simpan pengaturan, dan reset data.

---

### 3. Form Settings - Tab Theme & Visual (`03_Settings_Theme_Visual`)
* **Theme Palette & Colors Card:**
  - Pengatur 4 warna utama: Background (Latar Segmen), Border (Garis Tepi), Highlight (Warna Sorotan Kursor), dan Glow (Pendaran Neon).
  - Kotak warna mendukung kode Hex manual (misal: `#3b82f6`) dan dialog color picker sistem.
  - Toggle efek Neon Glow untuk menyalakan pendaran aura futuristik.
* **Scale & Blur Dimensions Card:**
  - Slider `Overlay Menu Scale`: Mengubah ukuran fisik menu radial dari 50% hingga 150%.
  - Slider `Transparansi`: Mengatur opasitas latar belakang segmen dari transparan penuh (0.0) hingga pekat solid (1.0).
  - Slider `Neon Glow Thickness`: Menentukan radius blur pendaran neon (10px hingga 100px).
  - Slider `Background Acrylic Blur`: Efek kaca buram modern pada latar menu.

---

### 4. Form Settings - Tab Inertia Scroll Flywheel (`04_Settings_Inertia_Flywheel`)
* **Fisika Inersia Kinetik:**
  - Mensimulasikan putaran roda mouse *flywheel* bermassa (seperti mouse flagship Logitech MX Master) pada mouse standar mana pun.
  - Slider `Friction` (0.01 - 0.99): Mengatur seberapa mulus deselerasi/pengereman guliran terjadi saat roda berhenti diputar.
  - Slider `Sensitivity` (0.1 - 10.0): Mengatur daya dorong akselerasi per klik putaran roda.
  - Perekam `Default Hotkey`: Tombol keyboard yang ditahan saat memutar roda mouse untuk memicu inersia scroll.
  - Toggle `Invert Scroll Direction` & `Enable Horizontal Scroll (Shift + Wheel)`.
* **Profil Hotkey Per Aplikasi:**
  - Memungkinkan pengaturan tombol hotkey, nilai gesekan, dan sensitivitas yang berbeda untuk setiap software (misal: tombol `Escape` untuk PDF-XChange Viewer, `Alt` untuk AutoCAD, `Ctrl` untuk Excel).
  - Tombol `🎯 Deteksi Jendela` mengidentifikasi nama executable (.exe) dan judul jendela secara instan.

---

### 5. Form Settings - Tab Profiles & Filters (`05_Settings_Profiles_Filters`)
* **Profile Management Card:**
  - Menyimpan konfigurasi menu terpisah untuk berbagai skenario kerja (misal: Profil AutoCAD, Profil Editing Video, Profil Coding, Profil Browsing).
  - Tombol `📤 Export Profile` dan `📥 Import Profile` untuk berbagi template konfigurasi antar perangkat atau rekan kerja dalam format JSON.
* **Active Window Action Filters Card:**
  - Menghubungkan profil radial menu ke software tertentu melalui filter `Window Title` atau `Executable File Name`.
  - Saat aplikasi target aktif di layar, radial menu otomatis beralih ke profil aplikasi tersebut tanpa intervensi manual.
* **Overlay Layout Sizing Card:**
  - Slider ukuran geometri presisi: Diameter lingkaran luar, radius lingkaran dalam, celah submenu konsentris, batas sudut kipas submenu, ketebalan border, dan padding tombol.

---

### 6. Modal Macro Step Runner Editor (`06_Macro_Step_Editor`)
* **13 Tipe Aksi Otomatisasi Terintegrasi:**
  1. `TypeText`: Mengetik teks panjang otomatis dengan jeda milidetik per karakter dan opsi simulasi keyboard fisik.
  2. `ActivateWindow`: Mencari jendela aplikasi berdasarkan judul / nama .exe dan membawanya ke latar depan, atau meluncurkan file `.exe` jika program belum berjalan.
  3. `MoveMouse`: Memindahkan kursor mouse ke koordinat X/Y, gerakan relatif, atau mencari posisi elemen visual di layar menggunakan **Smart Image Recognition (Computer Vision Template Matching)**.
  4. `RunCommand`: Menjalankan skrip PowerShell atau Command Prompt secara hening di latar belakang (*Silent background execution*).
  5. `ActivateShortcut`: Menjalankan kombinasi shortcut keyboard (misal: `Ctrl + Shift + S`).
  6. `PressKey` & `ReleaseKey`: Menahan atau melepas tombol keyboard tertentu dengan durasi presisi.
  7. `Scroll`: Menggulir roda mouse vertikal atau horizontal.
  8. `PasteText`: Menyuntikkan teks instan langsung melalui Clipboard.
  9. `Wait`: Jeda waktu milidetik antar instruksi.
  10. `SplitMacro`: Percabangan logika makro berdasarkan jenis klik mouse.
  11. `WaitForInput`: Menunda langkah berikutnya hingga tombol ditekan oleh pengguna.
